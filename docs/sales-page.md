# 2027 ToB销售专页

用户要求独立小页面、截图60家逐一检索、补充优质企业、本科可投优先。保留原建筑页面，不改其规则。

## 数据与执行

- `config/sales_companies.yaml`：按截图顺序保存六个行业各10家公司，另补充28家；公司别名单独配置。全量公开聚合来源逐家公司匹配；额外人工查询官方和高校来源。
- `config/sales_verified.yaml`：人工核验或补充的具体销售岗位，来源级别独立记录。
- `src/autumn_jobs/sales.py`：独立匹配与安全合并。明确实习、仅硕博和要求工作经验的职位不收入；专业限制不明则待确认。
- `site/data/sales.json`：岗位、校招公告、88家公司检索结果；原文不长期公开保存。
- `scripts/crawl_sales.py`：单独更新销售页，不覆盖建筑岗位数据。执行 `python scripts/crawl_sales.py --date 2026-10-10`；日常不用date参数。
- `scripts/crawl.py`：既有每日工作流在抓取后同时生成销售数据；最大翻页从17改为100，直到hasMore为false停止。

## 展示约束

岗位按公司合并；默认只展示具体岗位信息，公告可单独切换。公告中明确列出的销售岗位可拆为具名线索，但不继承整个公告的本科、专业或薪资要求；标明“2027公告列出”，资格待核验。不能据此声称全部本科可投。

搜索、行业、城市、资格筛选；整家公司不感兴趣、岗位已投递/不感兴趣并折叠；已处理筛选可恢复。浏览器localStorage保存，无跨设备同步。

薪资只有岗位原文明确给出的才展示；年薪预测不能写成保底。未知薪资提醒核对底薪、绩效、提成及达标条件。官方动态站无法读取不能断言无岗位。

## 验证

`python -m pytest -q` 覆盖规则及历史保护；`node --check site/assets/sales.js` 检查语法；浏览器验证加载、筛选、公司折叠、状态恢复、375px布局。GitHub Pages发布后检查sales.html与sales.json实际在线。

## 当前边界

“未发现”仅指配置来源没有找到。具名待核验线索与完整JD核验岗分别计数，主页面不承诺全网覆盖或面试概率。历史记录不因单次失败、列表缺失而删除；明确已过截止或closed才隐藏。人工补充记录仍需后续官网复核，不表示每天完整读取所有动态招聘系统。
