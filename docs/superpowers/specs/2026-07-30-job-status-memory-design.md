# 岗位状态记忆设计

## 目标

让用户区分待处理、已投递和不感兴趣岗位，减少重复查看。

## 存储与状态

- 使用浏览器 `localStorage`，键名为 `autumn-jobs-statuses`。
- 键为岗位 `fingerprint`，值为 `applied` 或 `not_interested`。
- 未记录的岗位为待处理。
- 状态仅在当前浏览器保存，刷新后仍保留，不同步到其他设备。

## 页面行为

- 每个展开岗位显示“已投递”和“不感兴趣”按钮。
- 标记后岗位不出现在默认待处理公司列表。
- 页面底部显示默认收起的“已投递（数量）”与“不感兴趣（数量）”区。
- 两个区域可展开查看岗位并使用“撤销”恢复为待处理。
- 公司的待处理岗位和已标记岗位独立分组，任何一个岗位不会被删除。

## 验证

- Node 测试覆盖状态写入、读取、撤销和待处理过滤。
- 现有公司分组测试继续通过。
