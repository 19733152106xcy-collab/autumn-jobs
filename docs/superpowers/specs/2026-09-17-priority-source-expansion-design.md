# 待遇优先与高价值来源扩展设计

## 目标

让岗位库在保持“建筑相关本科可投、非纯土木、非硕博硬门槛”的前提下，稳定发现城市更新、开发商设计管理、国际工程、建筑数字化和高质量外企岗位；同时让每日运行结果可解释。

## 方案

1. 新增华中科技大学就业网适配器：从其公开招聘列表的前若干页读取职位详情，以“高校就业网已核验”身份进入既有清洗流程。
2. 继续保留两层岗位池：建筑主投（A/B）与高质量跨行业冲刺（C）。C 类仅允许头部企业或外企，建筑相关岗位不受该门槛误伤。
3. 扩充城市更新、地产设计管理、国际工程、建筑科技的关键词与企业待遇配置，使综合评分优先呈现更值得用户投入时间的岗位。
4. 在爬取摘要中新增每个来源的“原始抓取数、入库数、筛除数”，并将当天入库数写入公开状态文件。页面可据此说明“今天为何没有新增”，避免把“抓到但不匹配”误认为“没有运行”。

## 数据与安全

只保存公开岗位的结构化信息和来源链接；不存原始 HTML、账号、Cookie、请求头或个人信息。高校就业网岗位默认使用详情页，官方投递地址只有在公开内容中明确出现时才写入。

## 验收

- 华中科技大学就业网可被测试桩完整抓取，能够读取列表、详情和发布日期。
- 每日摘要可区分抓取、通过和筛除数量。
- 城市更新、设计管理、国际工程、建筑科技关键词可入库；硕博硬要求和纯土木/机电岗位继续被挡住。
- 现有全部 Python、静态网页和代码质量测试保持通过。
